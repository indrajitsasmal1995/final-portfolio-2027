# Indrajit Sasmal, portfolio

Static site served by Vercel at https://indrajit.work.
`vercel.json` turns on clean URLs, so `dhs-tutor.html` is served at `/dhs-tutor`, and
permanently redirects the old address, indrajitwork.vercel.app, to the same page on indrajit.work.
Files under `assets/` are cached by browsers for a day, then refreshed in the background.
